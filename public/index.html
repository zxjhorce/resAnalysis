构建清单格式

使用构建脚本输出的通用清单。资源通过 id（优先）或路径匹配，所有体积单位为字节。

{
  "name": "release-1.2",
  "platform": "Android",
  "assets": [
    {
      "path": "Assets/Textures/hero.png",
      "size": 1048576,
      "hash": "sha256-content-hash",
      "bundle": "characters",
      "dependencies": ["Assets/Materials/hero.mat"]
    }
  ],
  "bundles": [{ "name": "characters", "size": 800000 }]
}

CSV 表头：path,size,hash,bundle,dependencies,type。多个 Bundle 或依赖用分号分隔，含逗号的字段使用双引号。

path,size,hash,bundle,dependencies,type
Assets/hero.png,1048576,abc,characters,,Texture

实际构建体积：优先使用完整的 bundles[].size；没有 Bundle 清单时统计资源体积。Bundle 压缩体积与资源体积不能直接混用。

缺失数据：体积可以省略，但总量将标为不完整；hash、依赖可省略，相应原因无法确认。原生 Unity Build Layout 等报告需要先转换为此格式。
